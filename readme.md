# Título

Para este projeto, inspirei-me na Bauhaus, utilizando formas geométricas simples e cores primárias para criar uma composição interativa.
A ideia foi explorar o uso de if e else, fazendo com que a cor, o tamanho e a forma mudassem conforme a posição do rato ou ao clicar, também aprendi a utilizar novas funções, como translate(), push() e pop(), que me ajudaram a centrar as figuras sem afetar os outros elementos, usei ainda windowResized() para que a tela se ajustasse ao tamanho da janela.
No geral, procurei experimentar as condicionais usar as que havia aprendido com os outros exercicios, e aprender novas funções, mantendo uma estética simples inspirada na Bauhaus.
